# Custom New Tab

新しいタブを、あなただけのダッシュボードに。

Custom New Tab は、Chrome の新しいタブページを、カレンダー・お気に入りサイト・ニュース・Google ドライブをまとめたダッシュボードに置き換える Chrome 拡張機能です。すべてのデータはブラウザ内で完結し、開発者のサーバーには一切送信されません。

## 主な機能

- **📅 カレンダー** — Google カレンダー（読み取り専用）と iCal URL の予定を月・週・日で表示
- **⭐ お気に入りサイト** — よく使うサイトをセクション分けして素早くアクセス
- **📰 ニュース** — Google News や任意の RSS から最新記事を表示
- **📁 Google ドライブ** — 最近使用したファイル・スター付きファイルの一覧表示（メタデータのみ・読み取り専用）
- **🎨 テーマ・レイアウト** — カラーテーマ・ウィジェット配置・列数を自由にカスタマイズ

## インストール方法

Chrome ウェブストアには公開していないため、[Releases](../../releases) から zip をダウンロードして手動でインストールしてください。

1. [Releases](../../releases) から最新の `custom-new-tab-vX.X.X.zip` をダウンロード
2. zip を任意のフォルダに展開
3. Chrome で `chrome://extensions` を開く
4. 右上の「デベロッパーモード」を ON にする
5. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダを選択

## プライバシー

本拡張機能はユーザーデータを収集・販売しません。Google API から取得した情報は新しいタブ上での表示のみに使用し、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。

- 紹介ページ・プライバシーポリシーは Firebase Hosting（`site/` ディレクトリ）で公開しています
