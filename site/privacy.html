🔒 Custom New Tab プライバシーポリシー

最終更新日：2026年6月10日

本プライバシーポリシーは、Chrome拡張機能「Custom New Tab」におけるユーザーデータの取り扱いについて説明するものです。

1. データの収集について

Custom New Tab は、開発者が運営するサーバーへの個人データの収集・送信・共有を一切行いません。本拡張機能が扱うデータはすべてユーザーのブラウザ内に保存され、保存先は用途に応じて次の2種類に分かれます。

  • 認証トークン・連携アカウント情報 — chrome.storage.local（お使いの端末内のみに保存され、他のデバイスには同期されません）
  • お気に入り・表示設定など — chrome.storage.sync（ユーザーのGoogleアカウントに紐づき、複数のChromeブラウザ間で同期される場合があります）

2. ローカルに保存されるデータ

以下のデータがブラウザ内に保存されます：

  • お気に入りサイト — 登録したサイト名・URL・セクション分類
  • カレンダー設定 — Googleアカウント（OAuth）のメールアドレス・アクセストークン・有効期限、およびiCal URL（名前・URL・カラー）
  • Googleドライブ設定 — Googleアカウントのメールアドレス・アクセストークン・有効期限、取得件数・デフォルト表示
  • ニュース設定 — 選択したニュースソース、カスタムRSS URL（設定時のみ）
  • テーマ設定 — 選択したカラーテーマ
  • 表示・レイアウト設定 — ウィジェット配置・列数・カラム幅・予定フィルタモード等のUI設定

上記のうち、Googleアカウントのアクセストークン・連携アカウント情報（メールアドレス・有効期限）は chrome.storage.local に保存され、お使いの端末内にのみ保持されます（他のデバイスには同期されません）。お気に入り・テーマ・レイアウト等のその他の設定は chrome.storage.sync に保存され、ユーザーのGoogleアカウントに紐づく複数のChromeブラウザ間で同期される場合があります。いずれのデータも、開発者が運営するサードパーティサーバーに送信されることはありません。

🔒 OAuthアクセストークンは設定のエクスポート対象から除外されています。インポート後はGoogleアカウントへの再ログインが必要です。

3. ネットワーク通信

本拡張機能は以下のネットワーク通信を行います：

  • Google OAuth 2.0（accounts.google.com） — GoogleアカウントによるCalendar / Drive連携の認証のため
  • Google Calendar API（www.googleapis.com） — Googleカレンダーの予定を取得・表示するため（連携時のみ）
  • Google Drive API（www.googleapis.com） — Googleドライブのファイル一覧を取得・表示するため（連携時のみ）
  • Google News RSS（news.google.com） — ニュース記事の取得・表示のため
  • iCal URL（ユーザー指定） — カレンダープロバイダーから予定を取得するため（設定時のみ）
  • カスタムRSS URL（ユーザー指定） — カスタムRSSフィードからニュースを取得するため（設定時のみ）
  • Google Favicons API（google.com/s2/favicons） — お気に入りサイトおよびニュース配信元のアイコンを表示するため

すべてのネットワーク通信はユーザーのブラウザから直接行われます。中間サーバーを経由することはありません。

4. 権限について

  • storage — 設定をローカルに保存・同期するために使用
  • identity — Google OAuth認証（Calendar / Drive連携）を実行するために使用
  • host_permissions（news.google.com、www.googleapis.com） — Google News RSS取得およびGoogle API呼び出しに必要
  • optional_permissions（tabs） — 開いているタブからお気に入りを追加する機能を使用した場合のみ、実行時にリクエストします。使用しない場合は不要で、いつでも拒否・取り消しが可能です
  • optional_host_permissions — iCal URLやカスタムRSS URLを登録した場合のみ、実行時にリクエストします

本拡張機能がリクエストするOAuthスコープと利用目的は以下のとおりです：

  • https://www.googleapis.com/auth/calendar.readonly — Googleカレンダーの予定を読み取り、新しいタブに表示するため（読み取り専用）
  • https://www.googleapis.com/auth/drive.metadata.readonly — Google Driveのファイル名・更新日時などのメタデータを一覧表示するため（ファイル本文は読み取りません）
  • https://www.googleapis.com/auth/userinfo.email — 連携したGoogleアカウントを識別・表示するため

5. サードパーティサービス

本拡張機能は、アクセス解析・トラッキング・広告・その他のサードパーティによるデータ収集サービスを一切使用していません。

6. データの共有

ユーザーのデータを第三者に販売・譲渡・提供することはありません。第3項に記載したネットワーク通信を除き、ブラウザ外にデータが送信されることはありません。

7. Google APIから取得した情報の取り扱い（Limited Use）

本拡張機能が Google API から受け取った情報の利用および第三者への提供は、Limited Use 要件を含む Google API Services User Data Policy に準拠します。

8. ポリシーの変更

本プライバシーポリシーは随時更新される場合があります。変更があった場合は、ページ上部の「最終更新日」に反映されます。
